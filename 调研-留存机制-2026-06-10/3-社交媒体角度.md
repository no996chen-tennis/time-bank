# 留存机制调研 · 社交媒体上瘾机制的伦理化反向利用

> 2026-06-10 · Claude 调研。总纲：社交媒体靠"可变奖励 + 社交义务 + 无限供给"让人离不开；时间银行应靠"**被动在场（widget）+ 回忆复利（memories）+ 只增不减的意义资产（存折）**"让人舍不得。

## 一、经典机制清单与判定

| 机制 | 判定 | 要点 |
|------|------|------|
| Variable Ratio Reward（老虎机） | **需改造** | 随机性只在"每日一抽"（今天重逢哪条回忆），绝不做下拉刷新换一条 |
| Infinite Scroll | **不可用，反向做卖点** | 刻意制造停止线索："今日回忆只有一条"，首页永远看得到底 |
| 红点 Badge | **极克制版** | 永不用数字角标；仅周年回忆/伴侣互存出现纯红点，24h 自动消失 |
| Push 通知 | **可用（最重要合法武器）** | 频率封顶每周 3-4 条；**供给型优先于索取型**；10 词内文案点击率 ~3 倍 |
| FOMO | **不可用** | 改造为 memento mori（对自己生活流逝的觉察），只能低频肃穆出现 |
| 点赞/评论循环 | **不可用（V1）** | V2 唯一可借用：伴侣间"对方也珍藏了这一刻"单向确认，无计数无公开 |

## 二、Snapchat Streaks vs Duolingo Streak

- Snapchat：义务对象是**他人**（社交互惠+人质感），青少年度假把密码交朋友代发保 streak；后期才付费恢复
- Duolingo：义务对象是自己 + Freeze 安全网（核心结论：**安全网是损失厌恶可持续的前提**）
- 移植：周节奏"连续记账"（一周任意一天存入即算）；**绝对红线：断签永远不能触碰已存入的瞬间**——存款永久保本应作为公开宣言

## 三、BeReal 教训（全报告最重要一段）

巅峰 73M MAU → DAU/MAU 早衰 → 2024-25 被 Voodoo ~5 亿欧元收购。死因：
1. **通知是索取而非给予**（每天 ping 要求劳动，新鲜感耗尽后变催债）
2. 随机时刻与真实生活对抗
3. 随机切片内容无聊 → 用户开始表演 → 差异化死
4. **没有沉淀资产**（内容看完即弃，没有"离开会失去的东西"）

→ 时间银行：通知以给予为主 / 绝不做时间窗惩罚（"2 分钟内""今天不存就过期"）/ 金库越厚离开成本越高 = 最伦理的留存

## 四、Locket Widget（与 Widget-first 最相关样本）

- 80M+ 下载、**9M DAU、2024 年盈利**（仅融资 $12.5M）；BeReal 崩了它长青
- 原理：留存主力是"被动收到爱人照片"的一方——价值直接出现在主屏幕，**把 push 降维成环境信息**；主屏幕是最贵广告位且 widget 不招人烦（用户自己放的）
- 移植：**Widget 即产品，App 只是金库入口**。中尺寸 = 余额+今日回忆轮换；小尺寸纯回忆版；锁屏+StandBy 床头相框；V2 加伴侣存入直达对方 widget

## 五、Facebook/Apple Photos 回忆重现工程

- Facebook On This Day 每天 **9000 万人**使用；必须有过滤安全阀（前任/逝者）
- Apple Photos：纯端上，充电闲置时跑知识图谱+美学评分 → V1 直接可抄
- 时间银行优势：素材全是用户手选的高意义瞬间，**垃圾率为零**
- 节奏：周年 > 月度 > 随机；**存入 7 天后即触发"7 天前的今天"**（冷启动关键）

## 六、微信红点的中国语境

- 朋友圈红点合法性：背后永远是认识的人的真实动作；视频号红点 = 最激进导流，引发怨言
- 中国用户已被训练出"强迫性消除"或"习得性无视"两种反射 → **时间银行差异化机会 = "零红点"作为产品人格**

## 七、反社交媒体产品怎么用"觉察"做留存

- one sec：PNAS 280 人 RCT，目标 App 打开次数 **-57%**
- Forest：森林=专注史可视化 + 真实种树（200 万+ 棵）
- 共同范式：**觉察本身可以是奖励，前提是觉察的成果被可视化、被累积**
- 移植"觉察资产三件套"：存折页 / 每周日晚一封信（陈述不评判）/ 里程碑卡片导出（V1 唯一社交出口，借微信传播，零后端）

## 八、红线清单（绝不能用）

无限滚动·算法 feed / 数字角标 / 日更强制 streak / 恐吓式倒计时推送（"又少了 X 小时"）/ 公开点赞计数排行 / 限时窗口 / 对他人动态的 FOMO

## Top 5 排序

1. **Widget-first 架构：余额 + 每日轮换回忆**（Locket 模式）
2. **回忆重现 + 周年推送**（用"7 天前"解决冷启动）
3. **照片事件触发的存入提示**（端上检测今天拍了家人合照 → 当晚轻推）
4. **周节奏存折连续 + 每周日晚一封信**
5. **里程碑卡片导出**（发给瞬间里的亲人本人 = 情感闭环 + 增长回路）
